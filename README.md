# 💱 Currency Converter – React Project

A modern and user-friendly Currency Converter web application built using React and Vite. This project converts currencies using real-time exchange rates fetched from the Frankfurter API and focuses on clean UI, smooth user experience, and core React concepts.

---

## 🚀 Features

- 🌍 Real-time currency conversion
- 🔄 Currency swap functionality
- 🎨 Modern gradient background with glassmorphism UI
- 📱 Fully responsive design
- ⚡ Fast performance using Vite
- 🧩 Clean component-based architecture

---

## 🛠️ Tech Stack

- React (Functional Components & Hooks)
- Vite (Fast build tool)
- JavaScript (ES6+)
- Custom CSS (No UI framework)
- Frankfurter Currency API

## ⚙️ How It Works

1. On page load, the app fetches available currencies from the API.
2. User selects the source and target currencies.
3. User enters an amount.
4. Clicking Convert fetches the latest exchange rate.
5. The converted result is displayed instantly.

## 🖥️ Installation & Setup

1. Clone the repository  
   git clone https://github.com/your-username/currency-converter.git

2. Navigate to the project directory  
   cd currency-converter

3. Install dependencies  
   npm install

4. Run the development server  
   npm run dev

5. Open in browser  
   http://localhost:5174
